# Contributing to Matrix Builder Panel

Thank you for your interest in contributing to the Matrix Builder Panel plugin!

## Development Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/davidcmcest/grafana_zabbix_table.git
   cd grafana_zabbix_table
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development**
   ```bash
   npm run dev
   ```

## Making Changes

1. Create a new branch for your feature/fix
   ```bash
   git checkout -b feature/my-new-feature
   ```

2. Make your changes
   - Follow the existing code style
   - Add tests for new functionality
   - Update documentation as needed

3. Run tests
   ```bash
   npm test
   npm run lint
   ```

4. Commit your changes
   ```bash
   git add .
   git commit -m "Add new feature: description"
   ```

5. Push to your fork and create a Pull Request

## Code Style

- Use TypeScript for all new code
- Follow the existing code structure
- Use meaningful variable and function names
- Add comments for complex logic
- Keep functions small and focused

## Testing

- Write unit tests for all new utilities
- Test edge cases
- Ensure all tests pass before submitting PR

## Pull Request Guidelines

- Keep PRs focused on a single feature/fix
- Include a clear description of the changes
- Reference any related issues
- Ensure all tests pass
- Update documentation if needed
