  MATRIX BUILDER PANEL v1.0.3 - PLUGIN COMPILADO PARA GRAFANA 10

Este directorio contiene el plugin YA COMPILADO y listo para usar.
NO necesitas npm, node, ni compilar nada.

VERSIÓN 1.0.3 - Corrige error de inicialización

═══════════════════════════════════════════════════════════
  INSTALACIÓN RÁPIDA (3 pasos)
═══════════════════════════════════════════════════════════

1. Copiar este directorio completo a Grafana:

   sudo cp -r COMPILADO /var/lib/grafana/plugins/matrix-builder-panel

2. Dar permisos:

   sudo chown -R grafana:grafana /var/lib/grafana/plugins/matrix-builder-panel

3. Reiniciar Grafana:

   sudo systemctl restart grafana-server

¡Listo! El plugin ya está instalado.

═══════════════════════════════════════════════════════════
  SI GRAFANA NO CARGA EL PLUGIN
═══════════════════════════════════════════════════════════

Editar /etc/grafana/grafana.ini y agregar:

[plugins]
allow_loading_unsigned_plugins = davidcmcest-matrix-builder-panel

Luego reiniciar Grafana.
